# MiniMax H3 音画智能缓存

MiniMax H3 的纯 Python 音视频缓存加速节点。插件只使用 ComfyUI 公开的模型包装接口，不修改 `ComfyUI/comfy/ldm/minimax/model.py`，不包含二进制扩展，也不访问网络。

## 安装

将整个文件夹放到：

```text
ComfyUI/custom_nodes/ComfyUI-MiniMaxH3-SmartCache
```

然后完全重启 ComfyUI。在节点搜索中输入“音画智能缓存”。

## 连接方法

把节点插在模型加载器与使用模型的节点之间：

```text
模型加载器
    ↓
MiniMax H3 音画智能缓存
    ├─→ 基础调度器
    └─→ 基础引导器
```

不要与 ComfyUI 内置 EasyCache、TeaCache 或其他模型缓存节点叠加使用。

## 参数

节点界面已经使用中文参数名。鼠标停留在参数名称或控件上会显示详细说明。

| 参数 | 默认值 | 说明 |
| --- | ---: | --- |
| 视频阈值 | 0.12 | 越大越容易复用，速度更快，但画面风险更高 |
| 音频阈值 | 0.06 | 越大越容易复用，但声音与音画同步风险更高 |
| 开始位置 | 0.15 | 前 15% 始终完整计算 |
| 结束位置 | 0.85 | 后 15% 始终完整计算 |
| 最大连续复用 | 1 | 达到次数后强制完整计算；1 最保守 |
| 缓存位置 | 自动 | 满足安全余量时使用显卡，否则本轮不保存缓存；不会偷偷切换到内存 |
| 详细日志 | 开启 | 在控制台显示命中与估算计算量 |
| 显存安全余量GB | 1.5 | 保存显卡缓存后必须保留的预计可用显存；可按机器负载提高到 2～3GB |

第一次测试建议保持默认值。固定提示词、Seed、参考素材、分辨率、帧数、采样器和步数，对比启用与旁路状态下的完整视频及音频。

## 注意事项

- 本节点是近似计算，会改变数学结果，不能宣传为严格无损。
- 高速动作、人脸近景、复杂遮挡、强参考动作、口型与声音同步任务应使用保守参数。
- 控制台显示的是按模型调用次数估算的计算量，不等于端到端实测加速比。
- “自动”和“显卡”都会执行显存预算检查；预计无法保留设定的安全余量时，本轮缓存会被拒绝，不会强行申请显存。
- Windows 下会同时参考 NVML 的物理剩余显存与 PyTorch 可分配显存，并采用更保守的数值，避免 WDDM 显存分页造成整机卡顿。没有 NVML 时自动退回 PyTorch 检测。
- `缓存位置=内存` 会增加内存与显卡之间的数据传输，只有明确选择时才启用，通常只适合显存不足且系统内存充足的情况。
- 插件更新缓存时按条件分片原位刷新，不再先创建一整块残差再复制，降低缓存刷新阶段的瞬时显存峰值。
- 安全检查拒绝缓存时，该步骤继续走 MiniMax H3 的原始完整计算，只是暂时没有缓存加速，不会因此修改输出。

## 开源基础

缓存判据基于 [EasyCache 论文](https://arxiv.org/abs/2507.02860)公开的运行时自适应变换向量方法，接入方式使用 [ComfyUI](https://github.com/Comfy-Org/ComfyUI)公开的模型包装接口。本插件不包含第三方二进制文件、私有核心补丁、第三方工作流或模型文件。
